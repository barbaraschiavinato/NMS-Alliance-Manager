# nms-core integration

This directory contains the MIT-licensed modules from
[elegra1965-source/nms-core](https://github.com/elegra1965-source/nms-core/tree/62ee771796c3f67ed1d290900b37358b2ff70a74/nms-core),
pinned to commit `62ee771796c3f67ed1d290900b37358b2ff70a74`.

The station card loads `system.js` client-side to calculate the system's
planet count and star type from its portal address and galaxy. The letter-map
data and name-generation assets are not included because this integration
does not generate names.
